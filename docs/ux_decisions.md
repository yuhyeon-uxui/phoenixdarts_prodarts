# UX Decisions (UX 의사결정)

## 1. 다트라이브(JAPAN) 위계를 그대로 차용하기로 한 결정
- **문제점**: PERFECT 기존 사이트의 메뉴 구조가 중구난방이며 위계가 명확하지 않음.
- **해결책**: 경쟁 사이트인 다트라이브(JAPAN)의 검증된 8단계 수직 위계를 100% 차용.
- **결정 사유 (UX 관점)**:
  - **사용자 습관 존중**: 일본 유저들은 파격적이고 새로운 동선보다, 익숙하고 예측 가능한 동선(보수적인 성향)을 편안하게 느낌.
  - **인지 부하 감소**: 구조(뼈대)를 익숙하게 유지함으로써 새로운 디자인 요소(다크 모드, 네온 컬러 등)를 받아들이는 데 시각적/인지적 피로도를 최소화.

## 2. 프로 선수 중심의 데이터 시각화
- **문제점**: 팬과 선수가 모두 섞인 타겟팅으로 인해 중요한 포인트나 랭킹이 잘 보이지 않음.
- **결정 사유**: 타겟을 '프로 선수'로 명확히 좁히고, 그들의 가장 큰 니즈인 '랭킹/포인트'와 '스폰서 로고' 노출을 극대화하기 위해 UI를 대시보드 및 다크 테마 리더보드 형식으로 전면 개편.
