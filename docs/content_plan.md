# Content Plan (콘텐츠 기획안)

## 1. 개요
기존 PERFECT(prodarts.jp) 사이트의 콘텐츠 위계를 선진 다트 플랫폼의 성공적인 구조(8단계 위계)에 맞춰 재배치합니다.

## 2. 메인 페이지 (One-Page Scroll) 콘텐츠 배치
1. **비주얼 (Hero)**: 프로페셔널한 심판/선수 사진 (어두운 배경 + 강렬한 조명)
2. **NEXT STAGE**: 다가오는 대회의 디데이, 일정, 장소, 엔트리 리스트 버튼
3. **프로모션 배너**: 특별 이벤트 (예: JAPAN ELITE 360 등)
4. **STAGE WINNER**: 직전 대회 남/녀 우승자 얼굴, 이름, 포인트, 스폰서 로고
5. **2026 RANKING**: 올해의 누적 랭킹 표 (스폰서 뱃지 포함)
6. **TOPICS**: 주요 뉴스 및 공지사항 카드 리스트
7. **SPONSOR**: 등급별(Special, Official) 스폰서 로고 그리드
8. **FOOTER**: 사이트맵, 고객지원 링크

## 3. 핵심 콘텐츠 전략
- **프로 선수 최우선**: 일반 팬을 위한 홍보보다는, 선수가 본인의 순위와 스폰서를 돋보이게 확인할 수 있는 '데이터 대시보드' 형태의 콘텐츠 구성.
- **이미지 최적화**: 텍스트를 줄이고 선수 얼굴, 트로피, 스폰서 로고 등 직관적인 시각 요소(Visual Elements) 중심의 배치.
