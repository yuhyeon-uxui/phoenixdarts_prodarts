# Troubleshooting & Risks (트러블슈팅 및 리스크 관리)

## 1. 레거시 데이터 호환성
- **이슈**: 기존 PERFECT 사이트는 상당히 오래된 시스템(PHP/WordPress 등)으로 구축되어 있을 확률이 높음. 새로운 React/Next.js 프론트엔드와 데이터를 통신할 때 API 포맷이 맞지 않을 수 있음.
- **해결책**: 백엔드를 당장 뜯어고칠 수 없다면, Next.js의 API Routes(BFF - Backend For Frontend) 패턴을 사용하여 중간에서 레거시 데이터를 모던 UI에 맞게 파싱(Parsing)해주는 어댑터 계층을 둡니다.

## 2. 브라우저 파편화 및 반응형
- **이슈**: 현장에서 다트를 치는 선수들은 최신 스마트폰부터 아주 오래된 폰까지 다양한 디바이스를 사용함.
- **해결책**: Tailwind CSS를 활용한 철저한 Mobile-first 반응형 설계. 최신 CSS Grid/Flexbox를 쓰되, 주요 레이아웃이 깨지지 않도록 Fallback 스타일을 함께 고려함.

## 3. 다크 모드 가독성
- **이슈**: 텍스트나 로고가 어두운 배경에 묻혀서 안 보일 수 있음. 특히 스폰서 로고는 본래의 브랜드 컬러를 왜곡하면 안 됨.
- **해결책**: 스폰서 로고 이미지들의 화이트 배경을 투명하게(PNG/SVG) 처리하고, 대비가 낮은 로고 밑에는 은은한 반투명 글래스 패널을 덧대어 시인성을 확보합니다.
