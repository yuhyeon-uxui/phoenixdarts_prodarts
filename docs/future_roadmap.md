# Future Roadmap (향후 로드맵)

## 1단계: 메인 페이지(One-page) UI 데모 개발
- 핵심 IA(8단계 위계)가 적용된 스크롤 형태의 다크 모드 랜딩 페이지 완성.
- 스폰서 로고, 랭킹 등의 시각적 디자인 컨펌 획득.

## 2단계: 하위 페이지 확장 및 라우팅
- [대회 안내], [기록/랭킹], [선수/미디어] 등의 카테고리에 맞는 서브 페이지 구축.
- Next.js App Router를 활용한 매끄러운 페이지 이동 구현.

## 3단계: 실제 데이터(API) 연동
- 기존 PERFECT 서버의 랭킹 및 포인트 데이터를 가져올 수 있는 API 통신 모듈 작성.
- 선수 로그인 및 회원 전용 페이지 토큰/세션 처리.

## 4단계: 모바일 최적화 및 고도화
- 현장(다트 경기장)에서 스마트폰으로 조회하는 선수들을 위해 모바일 UI(반응형) 퀄리티 극대화.
- 다크 모드 ⇄ 라이트 모드 전환 옵션 추가 여부 검토.
