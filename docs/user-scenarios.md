# User Scenarios (유저 시나리오)

## 핵심 페르소나: 프로 다트 선수 (Pro Darts Player)

### 시나리오 1: 본인 랭킹 및 획득 포인트 확인
1. 선수가 스마트폰이나 PC로 `prodarts.jp` 에 접속한다.
2. 스크롤을 조금 내려 메인 페이지의 **[2026 RANKING]** 섹션에 도달한다.
3. 다크 모드 배경 위에서 자신의 이름, 랭킹, 포인트, 그리고 **스폰서 뱃지**가 선명하게 보이는 것을 확인하고 만족감을 느낀다.
4. 순위 상승/하락 화살표를 직관적으로 파악한다.

### 시나리오 2: 다음 대회 일정 확인 및 참가 신청
1. 사이트 접속 직후, 가장 눈에 띄는 최상단 **[NEXT STAGE]** 대시보드를 본다.
2. 다음 대회의 날짜와 장소를 단번에 인지한다.
3. 대시보드 내에 있는 **[엔트리 리스트]** 버튼을 클릭하여 참가 신청 페이지로 진입하거나, 현재 신청된 선수 목록을 확인한다.

### 시나리오 3: 로그인 및 라이선스 갱신
1. 우측 상단 글로벌 네비게이션 바(GNB)에 고정된 **[선수 로그인]** 버튼을 클릭한다.
2. 프로 회원 전용 페이지로 이동하여 개인 정보를 관리하거나, 공지사항 카드 중 눈에 띄게 강조된 **[라이선스 갱신]** 카드를 클릭해 갱신 절차를 밟는다.
